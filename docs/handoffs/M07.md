# M07 Handoff — Reaction Builder

## Ownership

- `chem_wiki.modules.knowledge_catalog` 继续是 released catalog Reaction、参与者、物种显示字段和
  来源的唯一 read-data owner。它新增按 application material UUID 查找相关 catalog Reaction 的窄读取
  能力；不会建立第二套 Reaction 真值。
- `chem_wiki.modules.reaction_builder` 是候选已知反应的唯一 owner。`POST
  /v1/reaction-builder/candidates` 接受两侧的 material application UUID，并返回排序后的候选投影。
- `frontend/src/modules/equation_lab/` 保持 M05 用户交互 owner。`EquationDraft` 只保存用户锚点和历史；
  M07 所选 Reaction 是独立的短暂 selection state，canonical participants 仅在渲染时补全。

## Candidate semantics

- `reaction_builder` 对 reactant/product anchor 按 canonical participant application identity 做 side-compatible
  匹配。方向性 Reaction 维持 canonical 方向；`reversible: true` 的 Reaction 也可在有效反向中匹配。
- 排序是稳定且由后端拥有：已匹配锚点数、完成比例、缺失 canonical participant 数、`materialized` 优先于
  `catalog_only`，最后以 consolidated identity 打破平局。
- catalog-only 的 symbolic coefficient 与 non-species semantics 继续作为 catalog 数据保留；M07 不把它们
  转换为伪物种或 UUID。

## Equation Lab integration

- 工作台以单一 equation surface 呈现反应物、箭头和生成物，两侧均保留尾随空槽位。M05 的物态编辑、
  双击移除、拖放/跨侧移动、撤销重做、复制和手动 composition 行为保持可用。
- 多候选时，确定性首选位于中心，最多显示五个有用候选；替代候选使用受控压缩椭圆轨道，可悬停/聚焦放大并
  点击提升。窄视口切换为横向候选条，避免强行保留轨道几何。
- 唯一候选自动聚焦，显式选择也会聚焦。聚焦 Reaction 使用 canonical participants、coefficient 和
  reversible arrow，并紧凑展示反应类型、条件与来源。补全参与者为低调虚线投影，绝不写回
  `EquationDraft` 或其 undo/redo history。
- 配平仍通过 M05 `POST /v1/reactions/balance` 完成；自动配平收在可展开的“配平工具”内。界面不展示
  面向学习者的内部实现边界说明。
