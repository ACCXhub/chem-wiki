# M06 Handoff

## Structure Lab

- `chem_wiki.modules.structure_lab` 是 M06 后端唯一 owner；
  `POST /v1/structures/analyze` 接受 SMILES 与 molblock，执行解析、价态校验和规范化，
  并显式返回 `valid`、`invalid` 或 `unsupported`，不会把无效化学结构伪装为可发布结果。
- 有效结构返回 canonical SMILES、分子式、相对分子质量、重原子数、氢键供体/受体数、
  可旋转键数，以及用于二维描图和三维查看的稳定文本/坐标表示。
- `frontend/src/modules/structure_lab/` 是 Structure Lab 前端唯一 owner；
  `/structure-lab` 提供结构编辑、SMILES 输入、分析状态、RDKit 二维描图、3Dmol.js 三维查看、
  基础描述符与官能团交互，并分别处理 loading、HTTP error、invalid、unsupported、
  3D unavailable 和第三方 lazy chunk failure。
- `/structure-lab?species={application_species_id}` 通过 `knowledge_catalog` 的 accepted Structure
  entry 载入 canonical/isomeric SMILES，并立即走同一 RDKit 分析边界；手工 SMILES 仍保留。

## Organic and FunctionalGroup

- M06 catalog 建立 14 个稳定 FunctionalGroup UUID、名称、SMARTS 与模式来源；
  这些 identity 不依赖一次分析结果或第三方库对象。
- 检测结果绑定当前 Structure identity，包含稳定 FunctionalGroup identity、命中的原子索引、
  occurrence 数量与 provenance。二维视图可按 occurrence 高亮命中原子。
- 当前内容只发布来源明确的结构识别事实，为后续
  `Structure → FunctionalGroup → Property → Reaction` 链提供边界，不填充推测性的性质或反应知识。

## Integration boundaries

- RDKit 2026.3.5（BSD-3-Clause）只位于 M06-owned adapter；application Port、公共 DTO 和
  `chem_wiki.modules.structure_lab` 包入口不暴露 RDKit molecule 或其他第三方对象。
- Ketcher React/Core 3.17.2、Ketcher standalone 3.15.0（Apache-2.0）与 3Dmol.js 2.5.5
  （BSD-3-Clause）仅在 M06 前端 adapter 中集成，并通过 `/structure-lab` route lazy loading
  隔离，不进入首页首包或共享层。
- catalog 入口只投影已接受的 Structure record，不把 catalog/registry payload 或 provenance
  schema 暴露给 Ketcher、RDKit、3Dmol.js 或 React。
- Ketcher 中 Reaction Builder、reaction arrow/mapping、R-group、S-group、monomer 和内置
  分析/3D 工具保持隐藏；M06 不拥有这些能力。

## Preserved boundaries

- Reaction Builder、Atom Mapping、Bond Diff/Bond Change 均未实现。
- Mechanism、MechanismStep、Electron Flow 与任何机理推断均未实现。
- Synthesis、路线搜索、配方或生成式反应/性质内容均未实现。
- M06 未新增数据库表或 migration，也未改变 M01 Substance、Structure、FunctionalGroup、
  Reaction 的冻结分离。

## Representative chemistry verification

- SMILES 与 molfile 均覆盖；application contract 验证 engine 可替换且不暴露库对象。
- 甘氨酸验证 canonical SMILES、`C₂H₅NO₂`、羧基与氨基、稳定 FunctionalGroup UUID，
  以及各 occurrence 的原子索引。
- 非法价态 `C(C)(C)(C)(C)C` 明确返回 invalid；未知输入表示明确返回 unsupported，
  二者保持可区分。
- 前端测试覆盖编辑后分析、二维/三维联动、官能团 focus、loading/error/unsupported、
  编辑器失败后的 SMILES fallback 与 route lazy loading。

## Known non-blocking upstream observations

- 3Dmol.js 上游 bundle 使用 direct `eval`，production build 会给出安全/压缩提示。
- Ketcher route lazy-loaded chunk 约 23.95 MB（gzip 约 7.03 MB）；已隔离于 M06 route。
- 当前 Node.js 为 24.14.0，比 Ketcher 声明的最低 24.14.1 低一个补丁版本；现有测试、
  production build 与浏览器运行均通过，但环境升级时应消除此 engine warning。
