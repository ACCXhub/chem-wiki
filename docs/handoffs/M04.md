# M04 Handoff

## Established

- `chem_wiki.modules.element_wiki` 是 M04 后端 owner；`GET /v1/elements/{element_id}`
  使用 M01/M02 稳定 UUID 返回 Element Wiki read model。
- `frontend/src/modules/element_wiki/` 是 M04 前端 owner；M03 元素选择通过 App 级
  `/elements/{uuid}` 路由进入详情，breadcrumb 可返回周期表。
- 详情页提供 identity、classification、已校准属性、结构化知识 sections、Cytoscape 局部图和
  provenance/source 呈现。属性只有存在 M02 published selection 时才可用，单位、限定词、
  范围和 uncertainty 由 read model 保留；缺失值明确显示为“暂无数据”。
- API 只投影面向用户的来源 key、标题、publisher、URL、license 和字段列表，不暴露
  claim/source-record ID、raw payload、selection reason 或 M02 表结构。

## Catalog-backed knowledge graph boundary

- M04 graph DTO 使用稳定 UUID、显式 typed nodes/edges 和冻结的一组 M04 关系类型。
- `REACTANT_IN` 与 `PRODUCT_OF` 只能表达 `Ion/Substance → Reaction`；Reaction 保持独立节点，
  不允许退化为 `Substance → Substance` 边。
- 后端组合 M03 元素读模型、`knowledge_catalog`、teaching relation/index 与 reviewed
  consolidated knowledge，按学习优先级返回最多 4 ions、6 substances、6 reactions、
  3 concepts、3 phenomena。
- backend/read model 拥有节点身份、类型、边语义、排名与纳入；Cytoscape.js 仅拥有渲染、
  concentric layout、选择和轻量视觉过渡，不形成第二套图语义或通用 graph framework。
- `Ion/Substance → Element` 与 `Ion/Substance → Reaction` typed edges 均来自应用数据；
  reviewed Concept/Phenomenon 内容通过选择区与结构化 sections 呈现。

## Data and reuse decisions

- identity 与中文名继续使用 M02 已发布 IUPAC、官方中文补充和 Periodic Table PRO 最小中文
  seed；Periodic Table PRO 仅作为字段来源展示，没有复制 Wiki 文本、源代码或视觉资产。
- 属性继续使用 M02 已批准的 PubChem publication，并由 NIST ASD 校准中性原子第一电离能。
  M04 不引入新的科学内容来源，也不编写未经来源支持的 Wiki prose。
- Reaction 节点使用 consolidated Reaction ID 进入 `/equation-lab?reaction=...`；有 accepted
  Structure record 的 Ion/Substance 进入 `/structure-lab?species=...`。

## Current verification

- 聚焦读模型/API 测试覆盖 typed graph、bounded ranking、reviewed content 与结构入口。
- 真实数据库上 Na、Al、Fe、Cl、S 均返回非空 ions/substances/reactions/concepts/phenomena
  （可用时），图谱语义与 sections 一致。
- 浏览器 QA 覆盖 `1440×900` 与 `390×844`：Cytoscape 图渲染、节点选择、Reaction →
  Equation Lab、Species → Structure Lab 均可用；移动图视口有界，页面无横向溢出且 console 干净。
