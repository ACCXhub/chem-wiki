# M04 Handoff

## Established

- `chem_wiki.modules.element_wiki` 是 M04 后端 owner；`GET /v1/elements/{element_id}`
  使用 M01/M02 稳定 UUID 返回 Element Wiki read model。
- `frontend/src/modules/element_wiki/` 是 M04 前端 owner；M03 元素选择通过 App 级
  `/elements/{uuid}` 路由进入详情，breadcrumb 可返回周期表。
- 详情页提供 identity、classification、已校准属性、结构化知识 sections、局部基础图和
  provenance/source 呈现。属性只有存在 M02 published selection 时才可用，单位、限定词、
  范围和 uncertainty 由 read model 保留；缺失值明确显示为“暂无数据”。
- API 只投影面向用户的来源 key、标题、publisher、URL、license 和字段列表，不暴露
  claim/source-record ID、raw payload、selection reason 或 M02 表结构。

## Basic knowledge graph boundary

- M04 graph DTO 使用稳定 UUID、显式 typed nodes/edges 和冻结的一组 M04 关系类型。
- `REACTANT_IN` 与 `PRODUCT_OF` 只能表达 `Substance → Reaction`；Reaction 保持独立节点，
  不允许退化为 `Substance → Substance` 边。
- 当前仓库没有已审核的 Substance、Ion、Reaction、Phenomenon、Concept 或 Question 内容，
  因此局部图只返回中心 Element 节点，关联 sections 与 edges 返回真实空态。
- 未增加推测性的 graph persistence 或通用 graph framework。后续只有在对应 canonical 实体与
  审核来源存在后，才可通过 M04 owner 增加局部图记录；M09 Reaction Sphere 仍未开始。

## Data and reuse decisions

- identity 与中文名继续使用 M02 已发布 IUPAC、官方中文补充和 Periodic Table PRO 最小中文
  seed；Periodic Table PRO 仅作为字段来源展示，没有复制 Wiki 文本、源代码或视觉资产。
- 属性继续使用 M02 已批准的 PubChem publication，并由 NIST ASD 校准中性原子第一电离能。
  M04 不引入新的科学内容来源，也不编写未经来源支持的 Wiki prose。
- M04 局部图规模与当前空态不需要 Cytoscape.js 或 3d-force-graph；未增加前后端依赖。
