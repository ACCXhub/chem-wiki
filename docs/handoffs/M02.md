# M02 Handoff

## Established

- `chem_wiki.modules.element_data` 是 M02 的公共持久化与导入边界；它仅依赖
  M01 `chemistry_core` 的公共 surface。
- Alembic migration `20260820_01_m02_element_persistence` 建立六张 PostgreSQL
  表：`element`、`element_property`、`element_source`、`element_source_record`、
  `element_claim` 与 `element_published_value`。
- canonical `Element` 保持 M01 `ElementId` UUID 主键；`atomic_number` 是唯一、
  不可变的自然 upsert 键。M02 已 bootstrap 正式 1–118 号元素，保证原子序数、
  symbol、`name_zh`、`name_en` 完整且唯一。
- adapter → raw record → normalized claim → published selection → canonical
  property 的写入在同一事务内完成。source-specific payload 只进入
  `element_source_record.raw_payload`，不进入 M01 `Element`。

## Source roles

- Periodic Table PRO：116 个已有 `name_zh` 的事实种子；其 claim 以 `manual`
  selection 标记为非无条件权威，source reuse policy 为 `review_required`。
- 中国全国科学技术名词审定委员会官方中文补充：仅提供 117、118 号元素的中文名，
  不归属为 Periodic Table PRO。
- IUPAC：`atomic_number`、`symbol`、`name_en` 的权威 identity calibration；使用
  小型、版本化、可审计的事实 seed，而非运行时 PDF scraper。
- PubChem：批准发布 `electronegativity`、`first_ionization_energy`、
  `atomic_radius` 等补充属性；不能创建或改变 canonical identity。
- NIST ASD：仅校准中性原子的 `first_ionization_energy`。它保留 eV 原始值、
  uncertainty、Prefix/Suffix qualifier、reference key、ASD citation、来源 URL、
  获取时间及内容 hash，并取代同字段的 PubChem 当前 publication。

## Persistence, provenance and idempotency

- 每个已发布 canonical 字段通过 `element_published_value → element_claim →
  element_source_record → element_source` 保留字段级 provenance；落选 claim 不删除。
- canonical 属性只保存 source-neutral 当前值。NIST 的高精度电离能和 uncertainty
  保留在 claim；`element_property.first_ionization_energy_value` 按冻结的
  `numeric(10,3)` eV 表示物化。
- source 以 `source_key` upsert；相同 source record 由来源版本、record key、内容
  hash 去重；相同 claim 由 record、field 和 transform version 去重。重导入保持
  Element UUID、source record、claim 与 current selection 不变。
- 数据库约束和 deferred integrity trigger 同时保证 canonical 值与当前 published
  claim 一致；电离能比较按 canonical 列精度进行，避免丢失 claim 原始精度。

## Public boundaries for M03+

- 跨模块仅从 `chem_wiki.modules.element_data` 与
  `chem_wiki.modules.chemistry_core` 包根导入；不要依赖 adapter 的 CSV/JSON 字段、
  seed 文件布局或模块私有 helper。
- 可用公共入口包括 `bootstrap_element_identities`、`import_pubchem_elements`、
  `import_nist_calibrations`、相应 adapter、结果类型和持久化 mapping。调用方负责
  session/transaction 生命周期及先执行 migration。
- M02 不提供 repository、通用 ETL/resolver、后台任务、HTTP API、UI 或 Wiki 内容。
  M03+ 如需这些能力，应在自己的模块建立边界，不得把 source-specific 结构写回
  canonical Element。

## Live behavior and deferred work

- PubChem 与 NIST ASD adapter 均支持注入 fetcher/clock；确定性测试不访问网络。
  live smoke 分别需显式设置 `CHEM_WIKI_RUN_LIVE_PUBCHEM=1` 与
  `CHEM_WIKI_RUN_LIVE_NIST=1`，瞬态限流可跳过，其他接口变化应失败并触发适配器更新。
- 不实现 Periodic Table UI、Wiki prose/资产、Reaction 数据、NIST 光谱线/激发能级、
  电子构型、半径、电负性、原子量批量校准、NIST 全库摄取、多来源通用冲突 resolver、
  审核工作流、网络后台任务或 M03 功能。
- Periodic Table PRO 的许可仍需在未来再分发或扩展导入前复核；当前只存放最小事实
  seed，不复制其源代码、UI、图像或 Wiki 文本。
